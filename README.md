# opensustain.tech

The Next.js site for [OpenSustain.Tech](https://opensustain.tech) — a
directory and analysis of the open-source ecosystem in climate change,
sustainable energy, biodiversity, and natural resources. Statically exported;
no server, no API routes.

This repo's history starts as `web/` from
[opensustain.analytics](https://github.com/protontypes/opensustain.analytics),
filtered to just that subdirectory. It absorbs that Next.js app's analytics
dashboards and replaces the [mkdocs site](https://github.com/protontypes/open-sustainable-technology)
that previously served opensustain.tech. The project *list* itself stays
owned by that mkdocs repo's `README.md` — contributors keep sending PRs
there; this site reads it at build time. See `DATA_CONTRACT.md`.

## Requirements

- Node.js 18.18+
- pnpm

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Runs `scripts/fetch-data.mjs` first (see that file's header), then
`next build` with `output: "export"`. Static output lands in `out/`.

```bash
pnpm fetch-data   # refresh public/data/*.json on its own
pnpm typecheck
```

## Routes

| Path | What it is |
| --- | --- |
| `/` | Homepage |
| `/projects` | The project directory — see `DATA_CONTRACT.md` |
| `/analytics` | Landing page for the dashboards below |
| `/analytics/projects` | Project rankings, lifecycle, and attribute charts |
| `/organizations` | Organization geography, hierarchy, and rankings |
| `/topics` | Keyword and topic analysis |
| `/methodology` | Where the data comes from and its known limits |
| `/blog`, `/blog/[slug]` | *Not built yet* |
| `/about` | *Not built yet* |
| `/presentations` | *Not built yet* |
| `/privacy-policy` | *Not built yet* |

All routes are registered in `lib/navigation.ts`, including the four not
built yet — a page landing at exactly the path already wired up there is
enough to make it navigable.

## Data

- `app/globals.css` — the design system (tokens, fonts, light/dark themes).
- `public/data/*.json` — generated by `scripts/fetch-data.mjs`; gitignored
  (~10-12 MB, regenerated on every build). `public/data/fallback/` holds a
  small committed snapshot of each, used when no live source is reachable.
- `DATA_CONTRACT.md` — the `/projects` data source decision and the exact
  README/CSV match statistics behind it.
